Software é o conjunto de instruções que diz ao hardware o que fazer. Se o hardware é o corpo do computador, o
software é o que dá ordens a esse corpo — desde o sistema operacional até o navegador que você está usando agora.

## Tipos de software

- **Software de sistema** — gerencia o hardware e dá suporte a outros programas. O principal exemplo é o
  **sistema operacional** (Windows, Linux, macOS).
- **Software de aplicativo** — programas que o usuário usa diretamente para uma tarefa: navegador, editor de texto,
  planilha, sistema de chamados.
- **Software de programação** — ferramentas usadas para criar outros softwares: compiladores, editores de código,
  frameworks.

## Como um software "vira" algo que o computador entende

<Callout type="info">
Você não precisa decorar esses termos agora — eles voltam com mais profundidade na trilha de Lógica de Programação.
</Callout>

1. Alguém escreve **código-fonte** em uma linguagem de programação (Python, Java, etc.), que é legível por humanos.
2. Esse código é **traduzido** (compilado ou interpretado) para instruções que o processador entende.
3. O processador **executa** essas instruções — é aí que o programa "roda" de fato.

## Software livre, proprietário e como código aberto

- **Proprietário** — o código-fonte não é público; você usa sob licença (ex.: a maioria dos softwares comerciais).
- **Código aberto (open source)** — o código-fonte é público e pode ser estudado, modificado e redistribuído
  (ex.: Linux, Python).

## Resumo

Software é a parte lógica do computador: as instruções que fazem o hardware realizar tarefas. Ele existe em
camadas — sistema operacional, aplicativos e ferramentas de programação — e cada camada depende da anterior para
funcionar.
