Hardware é a parte física de um computador — tudo o que você pode tocar: processador, memória, disco, placa-mãe,
teclado, monitor. É o oposto de software, que é a parte "lógica" (os programas que rodam sobre esse hardware).

## Os componentes principais

- **CPU (processador)** — o "cérebro" do computador, executa as instruções dos programas.
- **RAM (memória)** — guarda temporariamente os dados que estão em uso; é apagada quando o computador desliga.
- **Armazenamento (HD ou SSD)** — guarda os dados de forma permanente, mesmo com o computador desligado.
- **Placa-mãe** — conecta todos os outros componentes entre si.
- **Fonte de alimentação** — converte energia elétrica para o computador funcionar.
- **Periféricos** — teclado, mouse, monitor, impressora: tudo que conecta o usuário à máquina.

<Callout type="info">
HD (Hard Disk) usa discos magnéticos giratórios; SSD (Solid State Drive) usa memória flash, sem partes móveis — por
isso é bem mais rápido e um dos upgrades mais perceptíveis em um computador lento.
</Callout>

## RAM x Armazenamento: a confusão mais comum

Muita gente confunde os dois porque ambos "guardam dados", mas o papel é diferente:

| | RAM | Armazenamento (HD/SSD) |
|---|---|---|
| Velocidade | Muito rápida | Mais lenta que a RAM |
| Permanência | Perde os dados ao desligar | Mantém os dados desligado |
| Função | Executar programas abertos agora | Guardar arquivos e programas instalados |

Se o computador está lento ao abrir programas, geralmente falta RAM. Se está lento para ligar ou salvar arquivos
grandes, o gargalo costuma estar no armazenamento.

## Como isso se conecta com o resto da TI

Um servidor é, no fundo, um computador com hardware mais robusto rodando continuamente. Entender hardware ajuda a
entender por que certas aplicações são lentas, por que um servidor precisa de mais memória, e por que
Service Desk/Help Desk frequentemente lida com troca de peças e diagnóstico físico.

## Resumo

Hardware é a parte física do computador. RAM guarda dados temporariamente para uso imediato; armazenamento (HD/SSD)
guarda dados permanentemente. Entender essa diferença já resolve boa parte dos diagnósticos de "computador lento".
