GitHub é uma plataforma online que hospeda repositórios Git na nuvem, adicionando recursos de colaboração que o
Git sozinho não oferece: interface visual, revisão de código, gestão de tarefas e um lugar público para mostrar
seus projetos.

## Git x GitHub, de forma direta

| | Git | GitHub |
|---|---|---|
| O que é | Ferramenta de controle de versão | Serviço online que hospeda repositórios Git |
| Onde roda | No seu computador | Na nuvem |
| Função principal | Registrar o histórico do projeto | Compartilhar, colaborar e revisar código |

Você pode usar Git sem GitHub (guardando o histórico só localmente), mas GitHub é o que permite que outras pessoas
vejam, contribuam ou usem seu código — e é, hoje, o principal lugar onde recrutadores olham o portfólio prático de
quem está começando em programação.

## Os recursos principais do GitHub

- **Repositório remoto** — uma cópia do seu projeto hospedada na nuvem, sincronizada com sua cópia local.
- **README** — um arquivo (`README.md`) que explica o projeto na página principal do repositório.
- **Issues** — um sistema para registrar bugs, tarefas e sugestões relacionadas ao projeto.
- **Pull Request (PR)** — uma proposta de alteração no código, que outras pessoas podem revisar antes de aceitar.
- **Fork** — uma cópia independente de um repositório de outra pessoa, para você modificar sem afetar o original.

<Callout type="info">
Alternativas ao GitHub existem, como GitLab e Bitbucket — todas usam Git por baixo, mudando principalmente a
interface e alguns recursos extras. GitHub é, hoje, a mais usada pela comunidade de código aberto.
</Callout>

## Um fluxo básico de colaboração

```
1. Você faz um "fork" ou clona um repositório
2. Cria uma branch para sua alteração
3. Faz commits nessa branch
4. Envia (push) a branch para o GitHub
5. Abre um Pull Request propondo a alteração
6. Alguém revisa e aprova (ou pede ajustes)
7. A branch é unida (merge) ao código principal
```

Esse fluxo é praticamente universal em projetos profissionais de desenvolvimento, seja em uma empresa ou em
projetos de código aberto.

## Perguntas frequentes

**Preciso pagar para usar o GitHub?**
Não — contas pessoais com repositórios públicos e privados ilimitados são gratuitas. Recursos avançados
(automações, times grandes) têm planos pagos.

**GitHub é só para quem já sabe programar bem?**
Não — é justamente uma das melhores formas de aprender na prática, documentando seu progresso desde o início.

## Resumo

GitHub hospeda repositórios Git na nuvem e adiciona colaboração: README, issues e pull requests. Enquanto o Git
cuida do histórico local do seu projeto, o GitHub é o que transforma esse histórico em algo compartilhável, revisável e
visível para outras pessoas — inclusive recrutadores.
