Inteligência Artificial (IA) é a área da computação dedicada a criar sistemas capazes de realizar tarefas que,
até pouco tempo atrás, exigiam raciocínio humano — reconhecer uma imagem, entender um texto, tomar uma decisão com
base em padrões, ou gerar conteúdo novo.

## Machine Learning: a base da IA moderna

Boa parte da IA atual é construída sobre **Machine Learning (Aprendizado de Máquina)**: em vez de programar regras
explícitas para cada situação, você treina um modelo com muitos exemplos, e ele aprende os padrões sozinho.

```
Programação tradicional:  Regras + Dados → Resultado
Machine Learning:         Dados + Resultado → Regras (aprendidas pelo modelo)
```

**Exemplo:** em vez de escrever regras manuais para identificar chamados de alta prioridade, você mostra ao modelo
milhares de chamados já classificados, e ele aprende a reconhecer os padrões que indicam alta prioridade.

## Deep Learning: um tipo específico de Machine Learning

Deep Learning usa **redes neurais** com várias camadas, inspiradas (de forma simplificada) no funcionamento de
neurônios biológicos. É a tecnologia por trás dos avanços mais recentes em reconhecimento de imagem, voz e,
principalmente, nos modelos de linguagem que veremos no próximo artigo desta trilha.

## IA generativa: criando conteúdo novo

IA generativa é um tipo de IA capaz de **criar** algo novo — texto, imagem, código, áudio — em vez de apenas
classificar ou prever. É a categoria que inclui os LLMs (Large Language Models), assunto do próximo artigo.

<Callout type="info">
Todo LLM é IA generativa, mas nem toda IA é generativa — muita IA aplicada no dia a dia (detecção de fraude,
recomendação de produtos, previsão de demanda) não gera conteúdo novo, apenas classifica ou prevê com base em
dados existentes.
</Callout>

## Onde a IA aparece hoje em TI

- **Suporte técnico** — chatbots e assistentes que ajudam a triar chamados antes de chegar a um analista humano.
- **Desenvolvimento** — ferramentas de IA que ajudam a escrever, revisar e depurar código.
- **Dados** — análise automática de grandes volumes de dados, identificando padrões que seriam difíceis de notar
  manualmente.
- **Automação** — agentes de IA capazes de executar tarefas de várias etapas (assunto de um artigo mais à frente
  nesta trilha).

## Perguntas frequentes

**Preciso saber matemática avançada para trabalhar com IA?**
Depende do papel. Para **usar** ferramentas de IA (como um assistente de código ou uma API de IA), não. Para
**criar e treinar** modelos do zero, sim — mas essa é uma fração menor das oportunidades de trabalho com IA hoje.

**IA vai substituir profissionais de TI?**
É um debate real e em andamento. O que se observa até agora é a IA mudando **como** o trabalho é feito — mais como
uma ferramenta que amplia produtividade do que uma substituição direta e completa das pessoas.

## Resumo

IA é a área voltada a sistemas capazes de tarefas que exigiam raciocínio humano. Machine Learning é a base mais
comum da IA atual; Deep Learning usa redes neurais mais complexas; IA generativa cria conteúdo novo, incluindo os
LLMs — o assunto do próximo artigo desta trilha.
