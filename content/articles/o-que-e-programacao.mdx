Programar é escrever instruções, em uma linguagem que o computador entende, para que ele execute uma tarefa. É
basicamente ensinar o computador a fazer algo passo a passo — sem pular etapas e sem assumir nada que você não
disse explicitamente.

## Um exemplo do dia a dia

Imagine explicar para alguém como fazer um café, sem deixar nada implícito:

```
1. Pegue a chaleira
2. Encha com água
3. Ligue a chaleira
4. Espere a água ferver
5. Coloque pó de café no filtro
6. Despeje a água quente sobre o pó
```

Isso é, essencialmente, um algoritmo — e programar é escrever esse tipo de sequência em uma linguagem que o
computador consiga interpretar, como Python ou Java.

## Por que o computador precisa de tanto detalhe?

Diferente de uma pessoa, o computador não "presume" nada. Se você pular um passo, ou for ambíguo, o programa não
funciona como esperado — ou simplesmente dá erro. Essa exigência de precisão é, ao mesmo tempo, a parte mais
frustrante e a mais valiosa de aprender a programar: ela treina um jeito de pensar estruturado, útil muito além do
código.

## O que você realmente aprende ao programar

- **Lógica** — decompor um problema grande em passos pequenos e claros.
- **Sintaxe** — a "gramática" de uma linguagem específica (Python, Java, etc.).
- **Depuração (debugging)** — descobrir por que algo não está funcionando como esperado.

<Callout type="info">
A lógica é transferível entre linguagens; a sintaxe, não. Por isso este site separa "Lógica de Programação" (o
raciocínio) de trilhas específicas como Python e Java (a sintaxe).
</Callout>

## Por onde começar

1. Entenda os conceitos desta trilha (variáveis, condicionais, loops, funções) sem se prender a uma linguagem ainda.
2. Escolha uma linguagem para praticar — Python costuma ser recomendado para iniciantes pela sintaxe mais direta.
3. Resolva problemas pequenos e reais, não só teoria.

## Resumo

Programar é escrever instruções precisas para que um computador execute uma tarefa. A lógica por trás disso é a
mesma em qualquer linguagem — dominar esse raciocínio é o que realmente separa quem programa bem de quem apenas
decorou sintaxe.
